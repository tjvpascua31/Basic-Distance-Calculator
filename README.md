# Basic Distance Calculator

## Description
Calculates the distance between two 2d cartesian points.

## How to Run
1. Download `dist.py` to disk
2. Run `dist.py` with a python interpreter (atleast 3.0+)

## Input Needed
`x0` `y0` `x1` `y1`

## Example
```markdown
Enter x1: 34
Enter y1: 1000000
Enter x2: -32
Enter y2: 0.00003

The Distance between two points is: 1000000.002```
